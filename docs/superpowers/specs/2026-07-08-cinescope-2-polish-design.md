# CineScope 2.0 深度打磨设计

日期：2026-07-08  
项目：`C:\path\to\douban-taste-recommender`
分支：`douban-crawler-ui-redesign`

## 背景

当前 CineScope Studio 已解决推荐页海报缺图、刷新回退、TVMaze/AniList/Jikan/TMDb/OMDb 多源海报等问题，但新的体验问题集中在四个方向：

1. 导演和演员图片仍依赖少量静态映射与豆瓣详情页，覆盖率不足；真实图片缺失时 fallback 还不够“资料页级”。
2. 推荐页 Hero 轮播是左侧竖海报 + 右侧文字，视觉不像世界级流媒体首页；缩略图与切换动效也不够高级。
3. 动漫候选池日本作品比例过高，缺少国创动画、欧美动画、成人动画、实验动画等维度。
4. 推荐算法偏单体得分排序，容易同类型、同地区扎堆；需要质量优先之后的多样性重排和解释。

## 目标

CineScope 2.0 的目标是把项目从“能用的推荐页面”提升为“私人影视策展产品”：

- 人物图不再大面积空缺；即便没有真人公开图，也以统一高级人物卡稳定呈现。
- 轮播从竖海报卡改成全宽电影横幅，支持分类独立焦点、缩略图胶片带、横向动效。
- 动漫分类扩展为全球动画剧集，保留日漫精品，同时纳入国创、欧美动画、成人动画与不同风格。
- 推荐排序先保证质量，再做多样性约束：媒体类型、国家/地区、题材、动漫地区、导演不过度重复。
- 所有改动继续本地优先，不保存 Cookie，不写入代理订阅地址。

## 方案

### 1. 人物图片韧性

新增前端人物图策略：

1. `peoplePhotoMap(r)` 保留现有豆瓣详情页、静态人物库和推荐结果自带 `people_photos`。
2. 新增 `personPortraitStatus(person)`，区分：`real`、`canonical`、`designed`。
3. `personPortrait()` 统一通过本地 `/api/image-proxy` 代理真人图；失败后切到高质量 SVG，不显示破图。
4. 人物卡显示“真实资料图 / 设计肖像”标识，避免用户把 fallback 当成加载失败。
5. 详情页人物区升级为 Spotlight Rail：大头像、角色、关联作品数量、点击筛选。

后端继续使用：

- `PEOPLE_PHOTOS_BY_DOUBAN_ID`
- `extract_people_photos()`
- `apply_curated_people_photos()`

并扩充精选人物映射，优先覆盖推荐快照中常见导演和主演。

### 2. 电影级横幅轮播

重写 `renderHeroCarousel()` 输出结构：

- `.cinematic-banner`：全宽 21:9 横幅容器。
- `.banner-backdrop`：用当前推荐海报做模糊背景。
- `.banner-poster-float`：浮动海报，不再压缩成左侧长条。
- `.banner-copy`：标题、类型、评分、简介、导演/主演、推荐理由。
- `.banner-filmstrip`：横向缩略图胶片带。
- `.banner-controls`：上一部 / 下一部 / 打开详情。

分类独立轮播：每个 tab 用 `state.heroBySection[name]` 保存位置，电影、电视剧、动漫不共用同一张图。

### 3. 动漫全球多样性

扩展本地候选池：

- 国创动画：如《中国奇谭》《伍六七》《雾山五行》《灵笼》《时光代理人》。
- 欧美动画：如《Arcane》《Blue Eye Samurai》《Invincible》《Primal》《Scavengers Reign》《Love, Death & Robots》《Avatar: The Last Airbender》。
- 保留日漫精品，但不让动漫分类全部被日本作品占满。

新增动漫子频道：

- `动漫 · 日漫精品`
- `动漫 · 国创动画`
- `动漫 · 欧美动画`
- `动漫 · 科幻悬疑`
- `动漫 · 成人动画`

### 4. 推荐算法多样性重排

新增 `diversify_recommendations(recs, limit)`：

- 输入：已按质量得分排序的 `Recommendation`。
- 输出：质量相近但更多样的推荐列表。
- 约束：
  - 同一媒体类型连续过多时降权。
  - 同一国家/地区连续过多时降权。
  - 同一导演重复时降权。
  - 动漫里日本作品占比过高时，给中国大陆 / 美国等动画加曝光。
  - 想看优先、超高分、强剧情仍保留较高优先级。

解释增强：

- `badges` 增加地区、质量标签、子频道标签。
- `short_reason` 更明确说明：高分剧情、类型补位、多样性补位、避雷处理。

## 验收标准

1. 全量单元测试通过。
2. 推荐页刷新后仍恢复第三步。
3. 页面图片审计：海报和人物图无浏览器破图。
4. 推荐页 Hero 是横向电影横幅，不再是左侧竖条轮播。
5. 动漫推荐里至少包含日本、中国大陆、美国三个地区中的两个以上；本地候选池必须包含非日本动漫剧集。
6. 推荐结果不是单一类型/地区堆叠，算法测试能证明多样性重排生效。
7. Cookie、代理订阅地址仍不落盘、不回显。
